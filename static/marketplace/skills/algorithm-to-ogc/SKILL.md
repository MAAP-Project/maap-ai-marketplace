## Overview

Convert a science algorithm into an **OGC Application Package** that conforms to
the [OGC API - Processes](https://ogcapi.ogc.org/processes/) standard, so it can
be described, discovered, and executed interoperably across MAAP and other
OGC-compliant platforms.

## When to use this skill

- You have an algorithm (e.g. a Python or containerized routine) and need an
  OGC-compliant Application Package description for it.
- You are preparing an algorithm for the MAAP Joint Algorithm Catalog or for
  deployment via an OGC API - Processes endpoint.
